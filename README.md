# Absenteeism Preprocessing

This project focuses on preparing a raw absenteeism dataset for analysis. The preprocessing stage is crucial for ensuring data quality, consistency, and usability in any data analysis or machine learning workflow. In this project, I demonstrate my ability to clean, structure, and engineer features from real-world HR-related data.

## Objective

Transform a raw absenteeism dataset into a clean and analysis-ready format. This involves handling missing values, correcting data types, renaming columns for clarity, and creating new features to support downstream analysis.

## Key Steps Performed

- **Initial Data Inspection:** Reviewed the structure, data types, and completeness of the dataset.
- **Handling Missing Values:** Identified and dealt with null values appropriately, based on domain knowledge and statistical methods.
- **Data Type Conversion:** Ensured consistency in date, numeric, and categorical fields.
- **Feature Engineering:**
  - Created new columns (e.g. total absence hours, absence category).
  - Extracted useful information from date fields (e.g. weekday, month).
- **Column Renaming:** Cleaned and standardized column names to improve readability.
- **Data Filtering:** Removed irrelevant or corrupted records to enhance data quality.
- **Final Output:** Saved a clean dataset suitable for exploratory data analysis or machine learning tasks.

## Skills Demonstrated

- Data cleaning with Python and pandas
- Feature engineering and transformation
- Handling categorical and datetime variables
- Preparing data for further statistical or machine learning analysis

## Next Steps

This cleaned dataset can now be used for:
- Absenteeism pattern analysis
- Predictive modeling (e.g., forecasting absenteeism)
